================================================================================
KROK 3: SPUSTENIE
================================================================================

Existuju 2 sposoby pouzitia - BEZ AI a S AI.


--- SPOSOB A: BEZ AI (formular) -------------------------------------------

Toto NEPOTREBUJE SAP AI Proxy ani ziadny kluc. Staci internet.

    python web/app.py

Otvor prehliadac: http://localhost:5000

Co mozes:
- Vyplnit: Odkial (BTS), Kam (STN), Datum, Pocet cestujucich
- Kliknut "Hladat lety" - dostanes real-time ceny
- Pridat/odobrat letecke spolocnosti (klik +/x)
- Aktivovat Google Flights ako kontrolu
- Zaslat vysledky emailom (checkbox + "Odoslat email")

Ako to funguje:
  Formular -> Flask server -> MCP Server -> RyanAir/WizzAir API -> ceny
  (Ziadna AI sa nezucastnuje!)


--- SPOSOB B: S AI (konverzacia) -------------------------------------------

Toto POTREBUJE SAP AI Proxy beziaci na localhost:6655.
Claude AI rozumie tvojej otazke a sam rozhodne co hladat.

    python agent/flight_agent.py

Priklad:
    Ty: Najdi najlacnejsi let z BTS do STN na 15.7.2026
    Agent: [vola search_flights] Nasiel som RyanAir za 19.99 EUR...

Prikazy: "quit" = koniec, "reset" = nova konverzacia


--- SPOSOB C: RYCHLY TEST (bez UI, bez AI) --------------------------------

    python test_search.py

Priamo testuje airline adaptery. Nevyzaduje ani Flask ani SAP Proxy.


--- SPOSOB D: AUTOMATICKY TEST AGENTA -------------------------------------

    python test_agent_prompts.py

Spusti 8 roznych use cases a zobrazi PASS/FAIL pre kazdy.
Vyzaduje SAP AI Proxy!

================================================================================
CASTE CHYBY
================================================================================

"ModuleNotFoundError: No module named 'mcp'"
    -> pip install mcp[cli]

"ModuleNotFoundError: No module named 'ryanair'"
    -> pip install ryanair-py

"ModuleNotFoundError: No module named 'fast_flights'"
    -> pip install fast-flights

"Connection refused" pri AI chat
    -> SAP AI Proxy nebezi. Spusti ho na localhost:6655.

"Address already in use" pri web server
    -> Port 5000 je obsadeny. Zmen v web/app.py: app.run(port=5001)

WizzAir vracia 429
    -> Retry mechanizmus to skusi 3x automaticky.
    -> Ak stale nefunguje: pockaj 5-10 min.
